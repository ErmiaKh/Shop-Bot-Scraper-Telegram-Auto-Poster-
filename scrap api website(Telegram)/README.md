# 🛒 Shop Bot (Scraper + Telegram Auto Poster)

این پروژه یک سیستم اتوماتیک است برای:
- دریافت محصولات از سایت ووکامرس (WordPress WooCommerce)
- استخراج اطلاعات (Scraping با Playwright)
- ارسال خودکار محصولات به کانال/گروه در پیام‌رسان بله (Telegram Bot API)
- جلوگیری از ارسال تکراری محصولات

---

# ⚙️ ویژگی‌ها

- 🔍 Scraping محصولات از سایت
- 🖼 دریافت عنوان + تصویر + لینک محصول
- 📤 ارسال خودکار به Telegram Bot
- 🧠 جلوگیری از ارسال تکراری (Deduplication)
- ♻️ اجرای مداوم با Runner
- ⚡ سبک و فلت (بدون فریم‌ورک پیچیده)

---

# 📁 ساختار پروژه
shop-bot/
│── telegram.py # ارسال پیام به بله (Telegram API)
│── scraper.py # استخراج محصولات با Playwright
│── main.py # مدیریت پردازش و ارسال
│── runner.py # اجرای دائمی پروژه
│── storage.py # مدیریت ذخیره لینک‌های ارسال شده
│── sent.json # دیتابیس ساده لینک‌های ارسال شده
│── test.py # تست‌های ساده
│── test_tg.py # تست تلگرام/ارسال (اختیاری)

نحوه کار:
سایت هدف (WooCommerce) لود می‌شود
لیست محصولات استخراج می‌شود
هر محصول باز شده و اطلاعات گرفته می‌شود:
عنوان
تصویر
لینک
بررسی می‌شود قبلاً ارسال شده یا نه
اگر جدید بود:
به کانال بله ارسال می‌شود
لینک در sent.json ذخیره می‌شود

نمونه خروجی پیام
🛍 عینک آفتابی اورجینال برند Prada

🔗 لینک: https://example.com/product/123

نکات مهم
سایت هدف باید ساختار HTML ثابت داشته باشد
اگر DOM سایت تغییر کند scraper نیاز به اصلاح دارد
از بلاک شدن جلوگیری شود (sleep در runner توصیه می‌شود)
بهتر است interval اجرای runner حداقل 3 تا 5 دقیقه باشد
🧩 تکنولوژی‌ها
Python 3
Playwright (Scraping)
Requests (API calls)
Telegram Bot API
📈 قابلیت توسعه

این پروژه می‌تواند ارتقا پیدا کند به:

سیستم چند کاناله (Telegram  + Bale)
پنل مدیریتی
دیتابیس حرفه‌ای (SQLite / MongoDB)
Queue system (Celery)
API server با FastAPI
